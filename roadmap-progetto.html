FASE 0
Prerequisiti — Prima di scrivere codice
Da cliente + agenzia
Logo in formato vettoriale (SVG, AI) o PNG ad alta risoluzione
Palette colori — codici HEX/RGB esatti
Pseudonimo/nome autore definito e approvato
PDF materiale didattico — almeno 2-3 documenti per i test iniziali
Conferma piattaforme (Facebook e/o LinkedIn)
Account Facebook e LinkedIn personali attivi del cliente
Verifica legale — compatibilità attività con ruolo dipendente pubblico (art. 53 D.Lgs. 165/2001)
Creare Facebook Business Account + Page del brand
Creare LinkedIn Company Page
Registrare Meta Developer App (developers.facebook.com)
Registrare LinkedIn Developer App (developer.linkedin.com)
Acquistare dominio (es. amministrativiinsanita.it)
Acquistare VPS (Hetzner o OVH ~€5/mese)
FASE 1
Setup Progetto
~2 giorni
Creare repository GitHub e struttura cartelle
Setup ambiente Python (virtual environment + requirements.txt)
Configurare file .env con tutte le chiavi API
Testare connessione a tutte le API (Claude, Meta, LinkedIn)
Setup logging e gestione errori base
FASE 2
Modulo Lettura PDF
~2 giorni
Implementare estrazione testo con PyMuPDF
Testare con i PDF reali forniti dal cliente
Gestire casi edge (PDF scansionati, protezioni, layout complessi)
Implementare chunking intelligente del testo
FASE 3
Motore AI Generazione Contenuti
~3 giorni
Integrare Claude API (Anthropic)
Definire prompt per ogni tipo di post (pillola, quiz, hook, ecc.)
Call calibrazione tono con il cliente (30 min) — approvare esempi output
Testare qualità output su materiale reale
Affinare prompt fino a risultato soddisfacente
FASE 4
Generatore Grafiche Brandizzate
~3 giorni
Ricevere e preparare asset brand (logo, palette)
Creare 2-3 template card con Pillow
Implementare overlay testo automatico
Adattare formati per Facebook (1:1) e LinkedIn (1.91:1)
Far approvare i template al cliente prima di procedere
FASE 5
Dashboard Approvazione Post
~4 giorni
Sviluppare app Flask con interfaccia web
Implementare preview testo + grafica per ogni post
Implementare azioni: approva / modifica / rifiuta
Aggiungere autenticazione (login sicuro)
Test con il cliente — raccogliere feedback UI
FASE 6
Pubblicazione Social
~4 giorni
Integrare Facebook Graph API — pubblicazione su Page
Integrare LinkedIn API — pubblicazione su Company Page
Fallback Buffer se LinkedIn API non approvata
Gestire refresh token e credenziali scadute
Test pubblicazione reale con post di prova
FASE 7
Scheduler Pubblicazioni
~2 giorni
Implementare APScheduler per pubblicazioni programmate
Configurare orari ottimali per ogni piattaforma
Testare ciclo completo: approvazione → coda → pubblicazione automatica
Notifica email al cliente dopo ogni pubblicazione
FASE 8
Landing Page
~5 giorni
Design wireframe — approvazione cliente prima di sviluppare
Sviluppo HTML/CSS responsive e mobile-first
Integrare form raccolta email con Brevo
Setup GDPR — consenso, privacy policy, cookie banner
Ottimizzazione velocità e SEO base
Deploy su VPS con HTTPS (SSL)
FASE 9
Test, Deploy e Consegna
~3 giorni
Test end-to-end: PDF → generazione → approvazione → pubblicazione
Deploy completo su VPS in produzione
Call di formazione con il cliente (1 ora) — walkthrough del sistema
Consegna manuale d'uso scritto
Prima settimana di monitoraggio post-lancio
